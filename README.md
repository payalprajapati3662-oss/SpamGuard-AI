# SpamGuard AI 🛡️

SpamGuard AI is a machine learning-based web application that classifies email messages as Spam or Not Spam.

## Features
- Email spam detection using Machine Learning
- Interactive web dashboard
- Animated scanning interface
- Spam or Not Spam prediction results
- Clear and analyze-again options

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- HTML
- CSS
- JavaScript
- TF-IDF Vectorization
- Multinomial Naive Bayes
